The funniest possible famous last words, carved as a single tombstone epitaph: a dying man uses his final breath not for wisdom, forgiveness, or a grand farewell — but to take the Wi-Fi password to the grave with him. The joke lands because the pettiness is total and the twist is instant: the most guarded secret of modern life, withheld forever, in one short line that reads exactly like something chiselled in stone.

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline, exactly one line of 32 characters.
